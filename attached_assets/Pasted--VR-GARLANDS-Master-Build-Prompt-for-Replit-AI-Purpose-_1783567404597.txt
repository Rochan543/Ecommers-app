# VR GARLANDS --- Master Build Prompt for Replit AI

> **Purpose:** Build a premium production-ready mobile application for
> **VR GARLANDS** that visually matches the attached reference screens
> as closely as technically practical while replacing branding and
> implementing the required backend.

------------------------------------------------------------------------

# 1. Project Objective

Build a React Native Expo application for **VR GARLANDS**.

The attached reference images are the visual benchmark.

The application should preserve the same premium experience: - Layout
hierarchy - Card styles - Spacing - Typography hierarchy - Rounded
corners - Shadows - Motion - Navigation patterns - Screen transitions

Only these functional changes are required:

-   Blinkit branding → VR GARLANDS
-   Grocery catalog → Flowers, Garlands & Pooja products
-   OTP login → Google Sign-In
-   Razorpay payments
-   Neon PostgreSQL backend
-   Node.js + Express API
-   Prisma ORM

# 3. Database

Use **Neon PostgreSQL** as the only database.

No Supabase. No Firebase. No MongoDB.

Everything must come from Neon PostgreSQL.

Create normalized tables:

-   users
-   profiles
-   categories
-   sub_categories
-   products
-   product_images
-   inventory
-   cart
-   cart_items
-   wishlist
-   orders
-   order_items
-   payments
-   payment_transactions
-   addresses
-   reviews
-   offers
-   coupons
-   banners
-   carousel
-   notifications
-   settings
-   support_tickets
-   delivery_slots
-   search_history
-   recently_viewed

Use UUID primary keys, foreign keys, indexes, timestamps, constraints
and Prisma migrations.
